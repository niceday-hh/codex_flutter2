# 历史任务标记与识别模型后台保留

- 历史任务保留首页的主题色标签样式，以图标和文字标注「仅一次／每天／每周…」及「语音开启／语音关闭／语音跟随默认」。标签适配全部强调色、浅色和深色主题，小屏自动换行。它们描述任务保存的配置，不表示历史循环仍在运行，也不使用历史记录中已经关闭的 `speechState` 推断语音开关。「跟随默认」不声称还原历史触发时的全局设置。
- 设置 → 语音录入 → 模型与性能新增「离线识别模型后台保留时长」，提供立即释放、15秒、30秒、60秒；未设置时默认30秒。设置搜索支持后台、保留、模型、预热、释放等关键词，结果预览显示当前值，保存反馈在分类弹窗内显示。
- 应用进入后台时立即请求停止录音；原生 Activity 的 `onStop` 仍停止录音器。模型计时从进入后台开始，重复暂停通知、录音结束或加载结束不延长窗口。返回前台取消计时，迟到的停录回调不能主动释放新前台的模型。
- 模型保留不增加安装包体积、不维持后台录音，也不承诺系统后台存活。内存压力、应用销毁和TTS合成允许提前释放；在用的识别会话仍按原有引用计数安全结束，TTS仍等待识别模型完全关闭。

验证覆盖模型四档时长、返回前台取消、慢停录、延期释放、内存／TTS优先释放、设置保存与搜索预览、历史标签在全部主题及320dp宽度的布局。自动化测试中的模型和麦克风使用替身；真实设备的进程存活和内存占用需另行实测。
