# 离线语音提醒

当前使用 Voine/VITS-MNN 的 VITS-uma-genshin-honkai 模型，804个音色条目，22050 Hz，五个模型模块和配置共61,336,225字节（APK压缩前）。具体来源与许可见 third-party-vits.md，逐文件校验记录在 tool/vits_model.lock.json。

设置 → 离线语音播报可搜索角色名或编号、试听、调整0.8～1.3倍语速，并独立控制锁屏是否朗读正文和重提醒是否再次朗读。默认不自动开启播报。旧AISHELL-3音色编号升级时重置为琪亚娜228，播报开关、时间和循环保留。备份导入也会迁移旧音色编号。

先持久化提醒排程，再在后台工作线程生成私有WAV缓存。识别模型完全退出后才加载MNN，合成结束释放全部模块；到点只由原生服务播放音频。中途关闭或生成失败时按原铃声／振动设置备用提醒，再次打开或设置中重试可补齐缓存。APK完全内置资源，录音与文本不上传。

锁屏保护默认只朗读通用提示，关闭后允许锁屏朗读正文。屏幕关闭且启用保护时停止正文，解锁不会额外触发一轮。语音播放结束仍算未读，划掉通知或确认后停止本轮剩余重提醒；归档／删除则停止以后全部提醒。试听使用媒体音量，到点播报使用闹钟音量。

主页完成记录自动集中收起，任务收纳支持按日期查看、搜索与复用。归档保留内容和参数并停用任务；编辑保存会重新启用。循环任务划掉通知只确认本次，不选择整理动作时仍按原循环继续。归档状态保存在备份中。

MEMO_RUN_REBOOT_TESTS=0；常规CI不执行adb reboot。设备测试验证合成与播放启动，不代表已实测荣耀100扬声器、物理振动或峰值内存。
