# 离线语音播报

使用 Voine/VITS-MNN 的 VITS-uma-genshin-honkai 模型，804个音色条目，22050Hz。模型和运行库内置，合成与播放无需联网。旧AISHELL-3音色升级时重置为琪亚娜228，原提醒时间、循环和播报开关保留。

## 音色与语速

在设置 → 离线语音播报或单条提醒编辑页，可选择音色、调整0.8～1.3倍语速，设置锁屏是否隐藏播报正文、重提醒是否再次朗读。单条任务选择“跟随默认”才采用全局默认值。试听使用固定短句，语速参数与正式播报相同；修改正文、音色或语速需要重新生成音频。

“新建任务随机音色”默认关闭。开启后，创建任务时从选定的配音来源与角色性别交集中抽取一次并保存；改时间、重提醒、循环触发、恢复排程和备份导入不重复抽取。编辑页可以重新抽取；音色选择弹窗的“随机挑一个”只选定这一个固定音色。设置页的随机试听只试听，不改固定默认音色。单条任务先试听随机结果时会保留该选择，保存后保持相同音色。

配音来源可选中文／日文／不限，表示音色的原配音来源。当前前端仍按中文文本朗读，不自动翻译、不增加日文文本识别或朗读前端。角色性别按已确认角色资料整理，不按声优性别或姓名猜测；未确认的角色只参与“不限角色性别”随机。详见音色分组说明。

## 准备与播放

保存提醒只确认排程，音频随后串行、异步生成，短提前量不保证已就绪。每批加载模型后释放，识别与合成错开运行以控制内存。请查看任务上的“语音已就绪”。首次可能还需生成通用锁屏提示；等待、加载、正文长度、音色、手机状态都会影响耗时。

到点仅播放已完成的私有WAV缓存；未准备好时按铃声／振动设置备用提醒，不在本轮稍后自动补播。正文／音色／语速相同且缓存保留时，修改提醒时间可以复用音频。设置中的“重新准备提醒语音”补齐缺失或失败音频，不改变提醒时间。

## 录音、历史与自检

波形显示现有16kHz单声道PCM录音的实际音量，10Hz上限、33个历史点，局部重绘；不代表音调或校准后的环境分贝。离开录音页、切后台或结束录音即停止并复位。

完成和主动保留的记录合并到“历史任务”，每条只显示一次。主动保留会停用后续循环；只划掉循环任务本轮通知仍保留原循环，除非选择保留并停用或删除。历史任务编辑保存后重新启用。

只有设置入口创建的自检任务带自动清理标记，默认在确认或划掉测试通知后删除，不再询问整理。可关闭此默认配置，关闭后新自检任务照常保留。普通备忘录即使正文也叫“后台提醒自检”也不会自动删除。自检任务经编辑页保存后转为普通任务。

## v0.9.0 免手录入
确认过程只使用应用内弹窗与离线语音识别，不生成或播放确认摘要。
单个语音会话持有识别资源；VITS新的合成操作等待会话结束，超时／离开后释放。
预听指令15秒、确认20秒；正文默认5秒无人声停录（可调3至10秒），录音最大45秒。
VAD识别人声活动，不识别说话人的身份；电视人声可能延长录音，保留手动结束。
