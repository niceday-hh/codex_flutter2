# 离线语音提醒

使用 k2-fsa/sherpa-onnx 官方发布的 vits-icefall-zh-aishell3，174个说话人，8kHz。资源包校验：ab468db3a3308cdd861495e0db2f25d79418a0c00639f74944c7cdf5dd8c6ec1。推理资源合计32,762,508字节，排除约129MB的rule.far，使用phone/date/number/new_heteronym FST规则。模型按需加载，不新增MNN库。

新提醒默认跟随应用默认播报开关（初始关闭），可单独开启/关闭。音色编号0～173，语速0.8～1.3倍，均可跟随默认。原有提醒升级后仍不自动开启播报。锁屏是否朗读正文与通知是否隐藏正文分开控制，默认锁屏只播通用提示。关闭“锁屏时隐藏播报正文”后允许扬声器读出完整正文。录音开始时停止本应用播放，避免将自身播报录入。

合成在App中的后台工作isolate执行。先持久化排程，再生成WAV缓存；中途退出造成缓存未完成时仍有铃声／振动备用提醒。再次打开App或设置中的重试会补齐音频。识别模型完全退出后才加载TTS，合成结束释放模型。长文本按48字符分块，单条最长15分钟；音频缓存限128MB，删除或修改提醒后清理无引用音频。

原生播放服务不依赖Flutter页面或模型加载；请求短时音频焦点，尊重系统音量/勿扰/后台限制。播放结束不算已读，手动确认才停止重提醒。切换为锁屏且启用正文保护时立即停止正在朗读的正文。每轮提醒依据当前锁屏状态选择正文或通用缓存；解锁不额外触发一轮。

导出仅含提醒参数和正文，不包含音频或手机内部路径；继承项导出为当时的有效值，导入后在本机重新生成。模型与数据来源：
- https://k2-fsa.github.io/sherpa/onnx/tts/pretrained_models/vits.html#aishell3-chinese-multi-speaker-174-speakers
- https://www.openslr.org/93/ （AISHELL-3语料，Apache-2.0）
- https://github.com/k2-fsa/sherpa-onnx （运行库，Apache-2.0）

测试约束：常规CI设置MEMO_RUN_REBOOT_TESTS=0，所有真实设备重启场景默认跳过。仅涉及开机恢复核心变更并获得该范围授权时才单独考虑重启验证。
