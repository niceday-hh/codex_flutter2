# 荣耀100真机验收

本清单尚未标记为已通过；云端编译不能替代真机验收。

1. 安装 APK，创建1分钟后的单次提醒，允许通知、精确定时，观察非全屏弹窗、铃声和振动。
2. 设置间隔1分钟、总次数3次。第一次通知不操作，应继续到第3次后停止；次数上限后 App 仍显示未读。
3. 第一次横幅自然收起，不清通知，仍应重提醒。仅点击通知进入 App，仍应重提醒。
4. 第一次通知手动划掉，剩余两次应取消；在 App 列表滑动／详情页滑动也应取消。
5. 同时建立两条提醒，确认其中一条不影响另一条。
6. 锁屏触发，保证只有占位文字，没有备忘录正文，也没有全屏覆盖；点击后需解锁才能进入 App。通知设置允许显示全部时重复测试。
7. 关闭铃声、振动与亮屏，分别验证；切换系统铃声及一次／三次／长振动。
8. 设置每日和多星期循环，确认新周期计数重新开始；旧通知的延迟确认不影响新周期。
9. 重启手机，原有提醒仍可触发；删除或编辑后旧闹钟不会再次触发。
10. 撤销精确定时、通知权限，观察页面状态和降级提示。关闭后台运行／强行停止后再打开，检查排程恢复提示及系统限制。
11. 在飞行模式下语音输入“明天下午三点半提醒我领取快递”“每周三上午九点提醒我开会”，检查识别结果、日期解析和确认流程。
12. 录音时锁屏或切到后台，录音应停止；取消、正常识别及异常后检查临时录音清理。
13. 确认首次识别有足够磁盘空间；字体放大、横屏、较长正文不会遮挡保存及确认控件。
