# 荣耀100真机验收

本清单尚未标记为已通过；云端编译不能替代真机验收。

1. 安装 APK，创建1分钟后的单次提醒，允许通知、精确定时，观察非全屏弹窗、铃声和振动。
2. 设置间隔1分钟、总次数3次。第一次通知不操作，应继续到第3次后停止；次数上限后 App 仍显示未读。
3. 第一次横幅自然收起，不清通知，仍应重提醒。仅点击通知进入 App，仍应重提醒。
4. 第一次通知手动划掉，剩余两次应取消；在 App 列表滑动／详情页滑动也应取消。
5. 同时建立两条提醒，确认其中一条不影响另一条。
6. 设置安全锁屏，并在系统通知隐私中关闭“显示敏感内容”。锁屏触发应只有占位文字，没有全屏覆盖；结束 App 进程后解锁，通知应显示正文，再锁屏应重新隐藏。系统若允许显示全部内容，按系统隐私设置决定显示效果；App 不能覆盖用户的系统选择。
7. 关闭铃声、振动与亮屏，分别验证；切换系统铃声及一次／三次／长振动。
8. 设置每日和多星期循环，确认新周期计数重新开始；旧通知的延迟确认不影响新周期。
9. 重启手机，原有提醒仍可触发；删除或编辑后旧闹钟不会再次触发。
10. 撤销精确定时、通知权限，观察页面状态和降级提示。关闭后台运行／强行停止后再打开，检查排程恢复提示及系统限制。
11. 在飞行模式下语音输入“明天下午三点半提醒我领取快递”“每周三上午九点提醒我开会”，检查识别结果、日期解析和确认流程。
12. 录音时锁屏或切到后台，录音应停止；取消、正常识别及异常后检查临时录音清理。
13. 确认首次识别有足够磁盘空间；字体放大、横屏、较长正文不会遮挡保存及确认控件。
14. 默认提醒选择“仅通知栏／不在锁屏显示”，新建提醒应继承；再编辑单条为“横幅和通知栏／隐藏正文”，其他提醒不应被修改。默认更改只作用于后续新建提醒。
15. 发送15秒测试，确认使用当前默认铃声、振动、展示与锁屏样式，且不重提醒。在系统隐私设置正确时，两种锁屏模式均不应显示正文或出现全屏覆盖；解锁不增加次数、重新响铃或误确认已读。
16. 创建多条相同样式，展开提醒自检中的通知样式，应只显示一组且关联数量正确；改变振动或展示后新增一组。删除全部关联记录后，仅当前默认组保留，无引用历史组在应用内隐藏。
17. 在编辑器打开当前样式的系统通知设置，不保存并退出，原任务时间与数量不变。修改某个系统通道会影响所有共用该样式的提醒，页面应提示与应用偏好不同。
18. 从 v0.2 覆盖升级，原数据和已手动修改的旧通道设置应保留；新字段缺失的旧 JSON 可导入，新版导出再导入保留展示及隐私选择。
19. 振动模式中先“试振”三次，确认不会改变当前选择；再点选三次，并发送15秒通知。比较应用试振与实际通知；到通知样式中查看系统记录的节奏、是否关闭以及差异提示。系统默认不保证次数，铃声选择不导入振动。
20. 若系统通道已被手动设为一次，应用不得强行覆盖；应显示节奏差异并允许打开对应系统页。确认勿扰、静音及振动开关对实际效果的影响。
