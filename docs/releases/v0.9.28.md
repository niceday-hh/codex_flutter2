# v0.9.28 · 正文保护与重提醒次数播报

多任务语音不再把全文中每个“几点／几分钟后”直接当成任务起点。先判断任务边界，再解析各条时间；“把火调小一点”“查看十点的会议资料”“加一点盐”等保留为正文。推荐使用“下一条”，兼容编号列表和“然后＋时间＋提醒我”；普通“然后检查门窗”留在当前任务。无标点“明天九点起床十点学习”仍可拆分。匹配用文本支持全角数字和空格，正文从原文提取，引用内容保留。

有“提醒我”的正文遇到含糊时间时，确认页显示疑似下一条，可选择“保留一条／拆成两条”；未选择前不能创建该条。可与上一条合并并进入编辑，恢复后一条原始时间文字，使用前一条设置并由用户确认。明确分隔后缺时间的条目仍保留，要求补齐；超过10条不截断原文。支持“再过十分钟”的参照选择：从录音基准时间或上一条计划时间起算。完成后计时依赖暂不自动建立，需改具体时间。每条设置独立，单任务模式规则不变。

任务编辑 → 语音播报新增“重提醒追加次数与间隔”，默认关闭，设置 → 语音播报可设新建任务默认值。首次只播报原内容；开启后从第二次起，正文后追加“当前为第n次提醒，提醒间隔X分钟”，使用实际次数及任务间隔。需同时开启语音播报与“重提醒时再次朗读”；每天／每周新一轮次数重新计数，首次仍不追加。

正文缓存保持原样，新增短话术按音色、语速、噪声参数及固定随机种子提前缓存，到点只播放已有音频，不加载模型。修改间隔或总次数仅补齐需要的话术；缓存不足或话术未就绪时仍播放已缓存正文，不临时合成。锁屏隐藏正文、取消／确认、录音接管与通话停止继续生效。试听及下载仍为选定的原正文音频，不包含某一次实际触发的次数后缀。

版本0.9.28+39，沿用固定包名、签名及完整离线模型。新增误拆正反例、原文保留、歧义确认、相对时间、合并、次数／间隔播报、缓存复用与参数持久化回归。正式验证结果以对应CI与设备报告为准，不宣称真机全场景验证。规则不能消除所有自然语言歧义，创建前请核对列表。
