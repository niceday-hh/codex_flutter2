# 定时备忘录 v0.1.0

面向荣耀100等 arm64 安卓手机的首个可安装体验版，最低 Android 8.0。

## 本版功能

- 紫色简约风 UI：备忘录、日历、语音、设置四个 Tab。
- 指定日期时间、单次、每天和按星期选择的循环提醒。
- 随 APK 内置中文 Paraformer int8 模型，语音在设备本地识别，无须在线下载模型。识别结果先进入编辑页确认，不会直接创建未经确认的提醒。
- 原生后台定时；重启、升级及时间／时区变化后恢复排程。
- 未读再次提醒：默认5分钟间隔，共3次（包括首次）；可逐条设置1–1440分钟、1–20次。
- 手动划掉系统通知或在 App 中滑动确认视为已读，立即取消本次剩余重提醒。点开通知、横幅自动收起不视为已读。达到次数上限后保留未读状态。
- 每个循环周期重新计数；新周期开始会取代该条提醒上一周期的未确认通知与剩余重提醒。
- 锁屏小型系统通知，隐藏提醒正文，不使用全屏界面、不解锁设备。查看正文需要解锁进入 App。
- 振动关闭、系统默认、一次、两次、三次及长振动；铃声可开关并从系统选择；亮屏可开关。
- 所有提醒仅保存于设备；无账号、无广告、无网络请求，录音识别后删除。

## 安装与使用

下载 `timed-memo-0.1.0-arm64.apk` 安装；首次保存提醒时允许通知，然后到 App「设置」开启精确定时。荣耀手机请在系统应用启动管理允许自启动、关联启动和后台运行，并检查电池优化及锁屏通知亮屏选项。

包名：`com.niceday.memo`。同时提供 APK 的 SHA-256 校验文件与构建信息。

## 验证范围与限制

发布流程要求 Flutter 静态分析、Flutter 界面与语音解析测试、原生日期／星期／重提醒边界测试通过，并检查 APK 内置模型和 arm64 原生库。

尚未进行荣耀100真机验收。安卓深度休眠可能延迟短间隔重提醒；勿扰模式、系统通知设置、后台限制及强行停止会影响提醒、振动、铃声和亮屏。亮屏为尽力执行，不能保证绕过手机系统策略。通知被系统自动整理不等于本次已读；用户「全部清除」属于手动消除，会确认对应通知。

语音时间解析覆盖常见中文表达；复杂表达、日期歧义或识别错误请在保存前手动检查。内置完整中文模型使 APK 较大；首次识别需复制模型到私有存储，请预留约700MB以上空余空间。
