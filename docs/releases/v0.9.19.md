# v0.9.19 · 时间滚轮、快捷延后、说一句时间

三条反馈其实是同一个问题：改时间这件事入口太少、精度太差，手势还会跑。

## 时间选择：从指针换成滚轮

原来的 `showTimePicker` 有三处别扭：改小时和分钟要拖表盘指针，指针细、外圈判定严，拖到一半手势被外层接走，卡片跟着动；分钟虽然理论上一格一分钟，手指拖动时却会吸附到最近的可见刻度，实际只能五分五分跳；表盘占满一屏，改完还要再点一次「确定」。

现在是一个 150dp 高的双滚轮：小时 0–23、分钟 0–59，每格 1 分钟，`FixedExtentScrollPhysics` 停在哪就是哪。选中项 26px，其余 22px，中间一条品牌浅底的选中带。

弹层显式关掉了下拉关闭（`enableDrag: false`）：滚轮本身就是竖直拖动，两个手势抢同一个方向，总有一个会被读成"没反应"。关闭走「取消」、右上角 ×、或点弹层外部。

## 快捷调整：四个按钮回答八成情况

编辑页的时间行下面、详情页的信息条下面，是同一排：

| 按钮 | 行为 |
| --- | --- |
| +15 分钟 | 当前显示时间 + 15 |
| +30 分钟 | 当前显示时间 + 30 |
| +1 小时 | 当前显示时间 + 1 小时 |
| 明天此时 | 当前显示时间 + 1 天 |

按钮基于**屏幕上正在显示的时间**，不是"现在"：点两次 +15 是 +30，而不是回到现在再加。如果显示的时间已经过去（编辑历史任务），基准自动落到 now——在过期时间上再加十五分钟只会得到另一个过期时间。

另有两个吸附：**整点**把分钟归零（这一小时的 :00 已过就顺延到下一小时），**现在**跳到下一分钟。

结果一律截断到分钟。界面上写 21:40，闹钟就不能在 21:40:53 响。

## 未触发的提醒：延后只改这一次

详情页（点任务行上滑）现在对「还没响、已启用、未结束」的任务显示「延后提醒」。点 +15 之后，toast 报出引擎真正排的时间（`已延后到 明天 09:15`），列表和详情同步更新，弹层不关，可以接着点。

原生新增 `ReminderEngine.postpone(id, at)`，和 `save` 的分工是刻意的：

| | `save` | `postpone` |
| --- | --- | --- |
| 循环任务的模板时间 | 改（以后每天都按新时间） | **不改**（明天回到 9:00） |
| 一次性任务的 `date` | 改 | 改（历史记录不能还写旧时间） |
| 递增 `version` | 是 | 是（旧广播必须被拒） |
| 清空 `attempts`、`archived` | 是 | 是 |
| 要求通知与精确闹钟权限 | 是 | 否（只是挪一个已经排好的闹钟） |

已经在响的任务不走这里：它的出口是确认或稍后，两者都在通知上。`postpone` 对 `activeOccurrence > 0 && !acknowledged` 直接返回 0，界面也不会显示这排按钮。

## 说一句时间

时间弹层底部有一个「说时间」，走现有的离线识别链路（同一个 `AsrSession`、同一套 VAD），但解析是独立的：

```
明天下午三点
30 分钟后
一个半小时以后
周三上午十点半
11 月 5 日 9 点
改成晚上八点
再晚 20 分钟
21:40
```

`parseSpokenTime` 不要求「提醒我」——这里没有提醒正文可拆。它接受一串动词前缀（改到、推迟到、换成、定在……），也接受叠加（「再晚」）。相对表达基于**当前选中时间**，所以「再晚 20 分钟」是叠加而不是重置；绝对时刻如果已经过去，无日期时顺延到明天，有明确日期时返回 warning 并禁用「确定」——不替用户编一个日期。

识别成功后面板回显「听到「明天下午三点」，已填入下方时间」，滚轮同步滚到 15:00；失败则提示重说，弹层不关。

## 小屏与大字

320dp + 1.6 倍字号下，时间弹层的内容比屏幕高。外层改成 `ConstrainedBox(0.92 屏高) + SingleChildScrollView`，滚轮缩到 116dp，预览行从 `Row` 改成 `Wrap`。这一条有测试守着：不溢出、`确定` 仍在。

## 校验

- `parseSpokenTime` 17 条单测：相对、绝对、周几、跨天、午夜变体、过期告警、非法日期。
- 时间弹层 7 条：初始值、快捷叠加、整点不落过去、分钟轮一格一分钟、过期禁用、可关闭语音、320dp 大字号。
- 延后 5 条（Dart）+ 2 条原生（Robolectric）：只挪 `nextTrigger`、一次性同步日期、已响拒绝。
- 全量：**173 通过 / 9 跳过 / 1 失败**，失败项仍是沙箱缺 VAD `.so` 的基线；CI 上装了 runtime，同一套测试通过。

数据结构、备份格式、包名与签名不变，可直接覆盖安装。
