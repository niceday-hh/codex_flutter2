# 超级提醒 v0.9.7（18）

本版将中文 TTS 向网页版原生合成流程对齐，重点减少人为节奏干预，并保留提醒场景的离线与缓存能力。

## 语音合成

- 取消正式合成中的标点时长上限与下限，让模型决定原始停顿；历史节奏策略仅保留用于开发对照。
- 中文分词改为离线 Jieba，减少系统分词与网页 Jieba 之间的词边界差异；轻声不再额外插入词内空格。
- 拉丁字母不再被清洗删除，支持中文前端字母名称读法，例如 APP；不等同于完整英语单词朗读。
- 语速弹窗显示 length_scale 0.1–2.0（越大越慢），可一键选用网页中文默认 1.2。保留原任务语速，不因打开设置自动修改。
- 两个噪声参数仍可独立调整，新生成随机，使用所选版本后，提醒、重提醒、试听、下载复用缓存。
- 短段尽量整体合成；大于约 100 字的长文本优先按句末、分句、词边界切分，并保留音素上限保护，不额外叠加拼接静音。

## 升级与验证范围

合成缓存版本变化，已有任务需要重新准备语音以采用新前端；任务时间、重复规则与随机种子保留。固定签名和应用包名不变。

Flutter 3.35.7、JDK 17、arm64；模型文件沿用固定校验值的 Voine VITS-MNN，未重新训练。发布仍由自动化的 Flutter、原生、Android API 33/35 实模型与提醒验证共同把关。

网页版日语与中日混合依赖 OpenJTalk，本版未接入；中文多音字词典与 Python pypinyin 尚非全量一致。自动测试和 WAV 对照不能替代手机实际听感验收。
