# 定时备忘录 v0.5.0（7）

适用于荣耀100等 arm64 安卓设备，沿用 v0.4.0 固定签名，可直接覆盖更新，保留现有备忘。

## 语音设置时间

- 支持“五分钟后提醒我喝水”“半小时后”“一个半小时后”“两小时十五分钟后”“两天后”等相对时间，也支持“提醒我五分钟后喝水”。
- 倒计时以结束录音时刻为基准，识别和确认的耗时不增加倒计时时长；文本输入以本次开始输入为基准。秒、毫秒完整保存至原生闹钟、开机排程及导入导出。
- 确认页显示目标日期及秒数。目标已过期时阻止保存，可手动选时间或明确点击“从现在起重新计时”，不会悄悄顺延。
- 缺失时间、非法日期（如2月30日）要求手动点选确认。已过期的明确日期不会自动改成次月或次年。
- 时间指令与“提醒我”后的正文分开解析，“明天九点提醒我整理每天的报表／看《后天》”不会误改日期或重复规则。

## 缩短识别等待

- 进入语音页时提前准备模型，在独立工作线程分块复制大模型，减少主界面等待及整包内存复制。
- 后台识别 isolate 在连续录音间复用同一 Paraformer 模型，每次仅新建识别流；离开语音页、应用退到后台或闲置60秒后释放。
- 显示模型准备、加载、就绪与识别阶段；录音识别完成后删除音频，避免旧识别结果覆盖新会话。
- 首次安装仍需准备模型，首次进入或释放后仍需加载；尚未在荣耀100实机测量延迟，不承诺具体秒数。

## 解锁亮屏弹窗

- 系统通知继续使用高重要性通道，并补充通知优先级；对应通道需在系统内允许“横幅／悬浮通知”。已有通道及用户选择予以保留。
- 应用在前台时显示可操作提醒对话框。
- 新增“设置 → 亮屏弹窗增强”，默认关闭。开启后在系统授权“显示在其他应用上层／悬浮窗”，即可在桌面或其他应用上方显示短暂小卡片；适用于“横幅和通知栏”提醒。
- 卡片10秒自动收起；自动收起、点“收起”都保持未读并按原设置重试。点“已读”或横向滑动确认已读，停止本轮重试。
- 卡片只在已解锁亮屏时显示，熄屏或锁屏移除；不使用全屏通知，锁屏继续隐藏正文。卡片服务短暂运行并显示静默状态通知。
- 悬浮窗权限未授予、被撤销或系统限制时，仍保留普通通知。部分系统、应用及勿扰模式可限制横幅或悬浮窗；不绕过这些限制。

## 验证与升级

发布流水线须通过 Flutter 静态检查、界面与时间解析测试、原生排程／通知／备份测试，以及 Android 13（API33）、Android 15（API35）的后台进程终止、Doze、重启恢复、锁屏隐私、可靠提醒服务与亮屏卡片测试。设备测试报告随 Release 提供；模拟器不验证荣耀系统实际触感或识别速度。
