# 定时备忘录 v0.6.0（8）

- 新增 AISHELL-3 VITS 完全离线语音播报，174个说话人音色（编号0～173），支持搜索、试听和0.8～1.3倍语速。
- 语音创建支持句末“开启语音提醒”“关闭语音播报”“只振动”等控制指令，与备忘正文分离；未明确指定时跟随应用默认，旧提醒保持关闭播报。
- 新增独立的“锁屏时隐藏播报正文”：默认只播通用提示，关闭后锁屏也可朗读正文；锁屏通知显示仍由原有设置控制。
- 保存排程后提前生成音频；提醒触发只由原生服务播放缓存，不需要打开 Flutter 页面。未准备成功按铃声／振动设置备用提醒。
- 重提醒复用音频，可设置仅首次朗读；播放结束不算已读，划掉或确认已读停止播放及剩余重提醒。
- 兼容部分 Android 15 系统对后台闹钟音频焦点的限制；播报保持使用闹钟音量，通话期间停止播报。
- 识别与合成串行加载，工作线程执行，合成后释放模型；缓存保存在应用私有存储，导入后重新生成。
- 备份保留播报参数；迁移时固化原有默认继承的有效音色、语速和播报开关。
- 延续固定发布签名，支持覆盖更新。

本次常规测试不重启手机或模拟器；重启恢复核心未变更。荣耀100扬声器效果、真实内存与系统后台策略仍需安装后验证。该模型为8kHz中文语音，音色数量不代表每种声音质量相同。
