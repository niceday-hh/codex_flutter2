# 超级提醒 v0.9.2（13）

本版基于v0.9.1，集中优化设置收纳、语音确认和前台交互。安装包为Android arm64固定签名版本，支持覆盖更新并保留本机提醒与配置。

## 设置：六个分类，减少长列表查找

底部“设置”Tab保留，首页改为两组简洁卡片和搜索入口：

| 分类 | 包含内容 |
| --- | --- |
| 提醒与通知 | 默认通知样式、铃声、振动、再次提醒间隔与次数、亮屏弹窗 |
| 语音录入 | 外部返回预听、静音自动停录、等待时长、本机识别、试用免手输入 |
| 语音播报 | 音色、语速、锁屏播报、角色组、音频准备状态 |
| 后台与权限 | 可靠提醒模式、服务状态、精确定时、后台运行与系统授权 |
| 任务与数据 | 历史任务、通知整理、导出备份、合并导入 |
| 帮助与诊断 | 提醒自检、通知样式、触发和恢复记录、诊断导出、使用提示 |

点击分类后打开可拖动、可滚动的磨砂子面板。搜索按分类名称、说明和参数关键词匹配，例如“自动停录”“铃声”“导入”。分类首页只展示入口，查看或关闭不会保存参数；原有设置值、备份格式和提醒调度行为保留。

## 语音确认：更清晰的内容与操作层级

- 移除“确认提醒”“请核对提醒内容”重复标题，首先显示首次提醒日期与时间，再显示正文。
- 用独立信息行展示语音播报状态、未确认时的提醒间隔和总次数，明确次数包含首次；已读后停止后续提醒。
- 使用白色与浅紫磨砂面板、柔和分隔及更宽留白。重新录音和手动编辑并排，确认创建作为主操作，取消放在下方；窄屏或大字体时次要按钮改为纵向。
- 整卡可滚动，兼顾长正文、小屏、横屏和放大字体。识别中、确认聆听和保存中的状态分别显示，保存期间阻止重复提交。
- 日期、时间不完整、已过期或参数存在歧义时，禁止直接创建并提示重新录音或手动编辑。语音确认仍不调用TTS。

### 录音文本中的提醒参数

支持在正文末尾组合说出“提醒间隔三分钟”“每隔3分钟提醒”“提醒五次”“总共提醒5次”“开启语音播报”等。示例：

> 今天22:30提醒我喝水，休息一下眼睛，每隔3分钟提醒，总共提醒5次，开启语音播报

正文为“喝水，休息一下眼睛”，间隔3分钟，总计5次（含首次），开启播报。未明确指定的参数继承原默认值。多次指定同一参数时，使用最后一个明确有效的值。

间隔支持1—1440分钟，总次数支持1—20次。含糊的“再提醒五次”、超范围数字或否定控制语句不会被静默修正；保留待核对内容并要求手动确认。只处理明确的尾部设置，避免把学习、研究或正文中间的普通短语误当作控制指令。

## 前台预听与模型生命周期

- 开启“打开应用后预听”后，冷启动或从桌面、其他应用返回时，按既有免手流程回到首页预听语音指令。
- 在应用内部切换Tab、切回首页或重复点同一Tab，不再触发新一轮预听。编辑器、待确认草稿和通知入口继续受保护。
- 用入口序号校验异步检查结果，避免迟到的“允许预听”结果抢走用户刚选择的页面。
- 已加载的Paraformer模型在本次前台使用期间复用，内部Tab切换不会因为20秒闲置回收而反复加载。前台保留不等于持续录音，模型预热本身不会打开麦克风。
- 切后台、内存压力及VITS生成播报音频时，仍请求释放识别模型；合成前继续等待释放，不让两套大模型同时常驻。快速退后台再返回时，旧的停止回调不会误释放新一轮前台状态。
- 继续共用原录音通道、识别工作单元、模型和现有线程数，保留冷启动音频有界缓存及按序补送机制。

前台复用会比v0.9.1的闲置20秒回收占用更久的内存，以换取再次使用时更少的冷加载。首次启动、首次授权、模型释放后的重新准备和麦克风被其他应用占用仍可能产生等待。

## 历史任务：第一次点击进入，重复点击不叠页

进入历史任务时立即取得导航锁并打开页面，录音停止通过原有串行队列异步完成，页面不再等待冷模型准备或停止录音返回。锁保持到历史页面关闭，连续点击也只存在一个历史页面，一次返回即可退出。分类设置中的历史入口先关闭子面板再导航。
