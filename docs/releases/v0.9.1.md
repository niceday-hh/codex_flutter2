# 超级提醒 v0.9.1（12）

- 优化手动录音：进入语音Tab提前预热模型，点击录音后开麦不再等待识别模型加载。冷启动音频有界缓存，模型就绪后按原顺序补送VAD；手动结束先停麦再识别，保留正确的相对时间基准。
- 继续共用单个录音通道、Paraformer识别模型与后台模型工作单元。新增PCM有效载荷缓存上限1,440,000字节（约1.37MiB）；分批补送、及时清理，不增加第二套大模型，不提高现有识别与VAD线程数。
- 前台连续录入可短暂复用模型，闲置20秒释放；切后台或内存压力时请求释放。VITS合成前等待识别模型关闭，预热不排队抢占正在进行的合成；已取消的录音不会在合成后重新加载模型。
- 补齐自动预听入口：开启“打开应用后预听语音指令”后，从桌面或其他应用返回时，不再受先前主Tab限制；主动点击首页也可重新预听。编辑、待确认草稿及本次通知入口继续受保护。
- 防止迟到的前台检查抢走用户手动选择的页面，防止旧VAD初始化结果或缓存混入下一次录音。
- 保留手动进入语音Tab、点击录音的操作方式。自动流程仍是首页预听指令→切语音Tab正式录入→弹窗确认；确认不播放TTS。
- 增加冷启动先开麦、缓存顺序／上限、提前结束、取消、模型失败、快速重录、资源驻留／TTS互斥及前台返回回归检查。

固定签名和包名com.niceday.memo.stable不变，支持覆盖更新。免手预听默认关闭，需在设置→免手语音操作中开启。
保留原有录音45秒上限、正文默认5秒静音停录、确认20秒超时，以及定时提醒、音色、备份功能。
本轮不执行手机或模拟器重启操作，未修改开机恢复排程核心。模型冷加载本身仍有成本，首次授权和麦克风占用也可能产生等待；荣耀100上的实际耗时、内存和YOYO行为需真机验证。
