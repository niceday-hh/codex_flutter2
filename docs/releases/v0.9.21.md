# v0.9.21 · 人物构图、柔和晕染与角色配色

## 详情弹窗

点开任务的上滑详情面板现在按人物有效区域构图：不再把透明留白一起缩小。横幅放大头肩和上半身；竖图延伸到卡片后方，脸部焦点优先保留在右上方，边缘武器、身体允许裁切。刻晴和琪亚娜的焦点经过单独校准，其余使用有效区域上部中心，个别特殊构图仍可能需要后续人工微调。

人物后方增加低饱和度径向色雾，左侧文字有局部渐变保护，图片下部在实际人物边界渐隐，避免横幅截断感。图片保持清晰，不使用整页实时高斯模糊。正文和按钮使用实色卡片；编辑按钮固定在底部，小屏和大字号可以滚动查看内容。

## 来自图片的日夜配色

使用 Google Material Color Utilities **0.4.0** 的 QuantizerCelebi、Score、Scheme 为 189 张图片预先提取主色并生成浅深色角色。透明像素不参与取色，244 个音色 ID 共用对应图片的数据。比如琪亚娜主色 #DE350A，浅色主按钮 #B62500，深色主按钮 #FFB4A3。

局部 Theme 同时替换 Material 颜色、按钮样式和 MemoTokens，避免只换背景而按钮仍用全局紫色。首页、设置及编辑表单继续使用用户的全局主题。错误、删除、成功等语义颜色保持稳定。未配图、语音关闭或样式数据缺失时回退到原有主题。

快捷延后四个选项保留，紧凑字号作用于实际标签，窄屏自动换行。音频试听、换一版、保存音频和任务调度逻辑不变。

## 资源与性能

没有新增或重编码图片，不保存白天/黑夜两套图片。新增的是本地构图和配色 JSON；弹窗读取缓存数据，不在打开时取色。仅解码当前角色，离开后清理图片缓存；无额外网络请求或循环动画。原始图片的清晰度上限不因布局放大而提高。

复现元数据：`npm ci --prefix tool/character-art`，安装 Python Pillow 后运行 `python3 tool/character-art/prepare.py`。依赖锁定在同目录 package-lock.json；输出为 assets/character_art/art_styles.json。

## 构建与验证

版本 **0.9.21+32**，沿用 Flutter 3.35.7、JDK 17、ARM64 和固定发布签名，包名 com.niceday.memo.stable，可以覆盖同签名旧版。

发布前运行 Flutter 分析、全量测试、原生提醒/语音/备份测试，以及 Android API 33/35 模拟器检查。新增验证覆盖全部配色的文字对比度、人物焦点、缺失样式回退、局部主题隔离、日夜横竖图及小屏大字操作可达性。

Release 附 character-ui-previews.zip，包含浅深主题的实际 Flutter 测试渲染。截图字体以测试环境为准，手机系统字形可能不同；不代表真机帧率或触感测试。TTS 模型、音频缓存与固定签名不变。
