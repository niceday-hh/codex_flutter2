# v0.9.14 · 行式列表、衬线标题与 iOS 触感

v0.9.13 解决的是"字太粗、深色分层不够"，这一版处理剩下的两件事：**页面结构**和**动效手感**。

## 列表从卡片墙改成行

之前每条提醒是一张独立卡片：圆角、边框、投影、左侧 3px 状态条。八条提醒就是八个盒子在抢注意力，这也是"页面很重"的根因——不是颜色，是容器太多。

现在整页只剩**一个容器**：顶部的主卡。下面的列表是行，行与行之间一条 0.7px 细线。

- 左侧 60dp 固定时间栏，时间 21px 等宽数字；下方是"今天 / 明天 / 11/2"的短日期
- 右侧标题 15.5px，未读时**只有时间变琥珀色**，不再多一个色块
- 状态胶囊只在"未读 / 未启用 / 已结束"时出现，其余情况只有一行 meta

固定时间栏是关键：所有时钟对齐成一条竖线，标题对齐成另一条，列表才开始像日程表而不是一堆便签。

## 衬线标题

新增一个 2.3MB 的中文衬线字体（思源宋体 SC，子集到 GB2312 + ASCII，OFL 许可），**只用在 19px 以上**：页面标题 34px、主卡标题 19px、详情正文 21px。

往下不用。宋体在 13–15px 时横画会掉到一个物理像素以下，标签会糊成灰块——所以列表行、按钮、设置项全部保持系统黑体。字号对比 + 字体对比，是这一版层级感的来源。

## iOS 风动效

| 项 | 之前 | 现在 |
| --- | --- | --- |
| 滚动 | Android clamping，到底硬停 | Bouncing，橡皮筋回弹，去掉拉伸光晕 |
| 入场 | 520ms，每项错开 85ms | 320ms，每项 36ms，附带 0.8% 缩放 |
| 按压 | 2.2%，110ms | 2.8%，120ms，配 `lightImpact` |
| 详情面板 | 300ms easeInOut | 上 260ms / 下 200ms，easeOutCubic |
| 主卡时钟 | 直接替换 | 180ms 上滑切换 |

第六项是**浮动按钮在向下滚动时收起**。它是唯一盖在内容上的控件，之前会压住最后一行；滚动时收起、停下 650ms 后回来，点击区域不变。

所有动画仍是一次性的：静止时不跑 ticker，不包整页 `Opacity`，不用 `BackdropFilter`。

## 底部导航

从"悬浮胶囊"改成通栏贴底 + 顶部细线。原来的胶囊在只有一个主卡的页面上等于又画了一张卡；现在选中态靠图标与文字变强调色，去掉了 Material 的药丸指示器。

## 验证

- 数据结构、备份格式、包名与签名不变，可直接覆盖安装
