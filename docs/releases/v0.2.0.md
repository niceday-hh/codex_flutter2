# 定时备忘录 v0.2.0

本版修复完成任务再次编辑后从主页消失的问题，并加强后台提醒、重启恢复和数据迁移。Android 构建号为 3。

## 主要变化

- 保存编辑后的任务会重新启用，清空旧周期状态并注册下一次提醒；主页也显示未启用记录，不再出现“只在日历存在”的隐藏记录。
- 首次提醒与未读重提醒使用 Android 系统闹钟 `setAlarmClock`；Android 13及以上声明正常闹钟精确权限，Android 12需要用户授权。不再缺少精确定时权限时静默降级为近似提醒。
- 到时提醒、未读重提醒和手动消除广播使用前台优先处理，降低繁忙开机期间后台广播排队造成的送达延迟；升级恢复排程时重建广播令牌，使已有提醒也使用新的处理优先级。
- 通知使用高重要性闹钟通道，并在保存时创建通道。设置页新增15秒提醒自检、实际触发时间、开机恢复时间和通知通道设置入口。
- 支持进程结束后的系统闹钟触发，以及开机广播恢复。首次解锁前只使用不含正文的设备加密排程信息；正文保留在凭据加密存储中，锁屏通知继续脱敏、非全屏。
- 设置页可导出 JSON 备份，并合并导入。导入前校验完整文件，错误文件不改动现有数据；导入记录使用新 ID，不覆盖原提醒；过去的单次任务归档；跨设备铃声使用系统默认。重复导入会产生重复记录，默认设置不被导入文件覆盖。
- 后续版本使用固定发布签名，并校验签名证书 SHA-256，禁止回退到临时测试签名。签名缺失时只生成标为 unsigned 的构建产物，不发布为可安装版本。

## 旧版迁移与安装

新版包名是 `com.niceday.memo.stable`，桌面名称为“定时备忘录·新版”。它可与 v0.1.0 并存，因此无须先卸载旧版，也不会清除旧版数据。旧版临时签名私钥未留存，不能用新签名直接覆盖旧版。

旧版尚无导出功能，其私有数据不能被另一个应用直接读取。请保留旧版，查看并迁移重要提醒；确认迁移后再自行决定是否移除旧版。安装新版后，后续使用相同固定签名、相同新版包名的版本可直接覆盖更新。

## 权限与验证范围

从最近任务中划掉 App、正常后台进程被系统回收，与“系统设置→强行停止”不同。原生系统闹钟不依赖 Flutter 界面持续运行；强行停止会让系统禁止应用任务和广播，需要用户重新打开应用，第三方 App 不能承诺绕过这一限制。

横幅、锁屏通知、铃声与振动最终受手机通知通道和勿扰设置控制。请在设置页发送15秒测试提醒，返回桌面等待；若记录显示已经触发而没有横幅，使用通道入口检查允许横幅与锁屏显示。荣耀仍需按系统实际策略允许后台启动及自启动。

发布要求静态检查、页面与语音规则测试、原生任务状态／通知／备份／Direct Boot 测试，以及 Android 模拟器的进程结束、休眠和重启排程验证通过。没有进行荣耀100真机验收，模拟器结果不能替代厂商系统实测。
