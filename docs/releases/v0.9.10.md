# 超级提醒 v0.9.10（21）

本版先修一处上一版引入的卡顿，再补四项观感与三项功能。最大的变化是深色模式：底色不是反色，而是带紫调的近黑，全部文字重新校过对比度。数据结构、备份格式、包名与签名均不变。

## 修复：Tab 切换变卡

上一版给 Tab 容器套了一层整页淡入，代价被低估了：

- `Opacity` 低于 1 会强制 Flutter 把整页光栅化到离屏缓冲。393×852 dp、dpr 2.75 约 253 万像素，每帧写一遍再读回来合成，约 20MB 显存带宽。
- 同时叠加的 6px 上移是 `Transform`，每帧变化会让整棵子树重新绘制——首页的滚动列表、阴影、渐变全部重放。
- 200ms 在 120Hz 上是 24 帧，等于连续 24 次全屏 `saveLayer` 加强制重绘，8.3ms 的帧预算直接被击穿。

现在页面之间不加任何合成层，直接切换；每个 Tab 页包一层 `RepaintBoundary`，顶部语音横幅或 SnackBar 出现时不再连带重绘后面那一页。切换反馈交给 `NavigationBar` 自带的指示器动画与已有的触感。新增守卫测试会从 `IndexedStack` 往上一路走到 `Scaffold`，链路上出现 `Opacity`／`AnimatedOpacity`／`FadeTransition`／`Transform`／`BackdropFilter` 即失败。

## 观感

- **按天分组，组头吸顶**。首页由一条长列表改为「今天／明天／本周／更晚」四组，组头在组内滚动时固定在顶部，并显示该组条数。分组按提醒的显示时间（`displayDate`）计算，重提醒未处理时仍落在原来那天。
- **主卡按时段换色**。渐变分三套：05–10 晨间紫橙、10–17 品牌紫、17–05 深夜蓝紫。早上和深夜打开不再长得一模一样。
- **空态插画**。用 `CustomPainter` 画的便签与铃铛线稿，随主题取色，不引第三方包、不加资源、不增包体。
- **深色模式**。见下节。

## 深色模式

调色板从一组静态常量改为两份语义实例（`MemoPalette.light` / `dark`），排版样式绑定调色板（`MemoType`），组件统一通过 `context.colors` 与 `context.text` 取色。深色底是带紫调的近黑 `#121017` / `#1B1822`，不是把浅色调暗，也不是简单反色——反色会让品牌紫变灰。

对比度全部按 WCAG 2.2 AA 重算：正文 15.4:1、次要文字 7.1:1、链接紫 5.4:1、输入框边界 5.4:1（非文本 UI 需 3:1）。未读标签在深色下原来是深橙底白字，只有 3.0:1，改为亮橙底深字，8.7:1。

`MaterialApp` 同时给出 `theme` 与 `darkTheme`，`themeMode` 跟随系统；状态栏与导航栏图标亮度随主题翻转，不再固定深色。目前没有 app 内开关。

## 功能

- **全局搜索**。首页右上角进入，可搜内容、日期与重复规则；结果按「还能处理」优先排序，点开即跳转详情。
- **多选批处理**。长按任意卡片进入选择模式，可批量「完成」或「删除」，删除前二次确认。选择模式下关闭滑动删除——横向拖动会和点选手势打架；主卡与新建按钮同时隐藏，把空间让给列表。
- **同一时间冲突提示**。保存时若同一分钟已有另一条启用的提醒，提示「同一时间还有 N 条」，但不阻止。同时排两条是常见需求，用户只是不想在到点时才知道。
- 批量删除与归档在 store 层新增 `deleteAll` / `archiveAll`，仍是逐条调用原生排程，只是省掉每条之后的重载。

## 升级与验证范围

不涉及数据迁移：提醒、历史、角色组、设置与备份格式完全兼容，可直接覆盖安装；已排程的系统闹钟不受影响。

Flutter 3.35.7、JDK 17、arm64。新增守卫测试：Tab 容器合成层禁令；深色调色板自有用色对比度断言（正文、次要文字、链接、输入框边界、页面与卡片必须不同色）。全部 Flutter 测试、原生排程检查、发音时长策略与 Android API 33/35 模拟器回归仍由自动发布流程把关。

界面观感以 393×852 尺寸截图核对，测试环境字体与真机存在细微差异；动画手感、触感与滑动阻尼仍需真机确认。
