# 定时备忘录 v0.7.0（9）

- 离线播报替换为 Voine/VITS-MNN 的 VITS-uma-genshin-honkai 模型。移除 AISHELL-3 模型和旧规则文件，使用 MNN CPU 推理。
- 提供804个音色条目，保留上游角色名称，支持按角色名／编号搜索和试听；语速、锁屏播报隐私和重复朗读开关继续可用。音色效果和中文发音以实际试听为准。
- 旧 AISHELL-3 音色编号与新模型不通用，升级时重置为琪亚娜（228），保留原播报开关、提醒时间和循环设置。请在“设置 → 离线语音播报”重新选择喜欢的音色。
- 继续提前生成私有音频缓存，识别与合成错开运行，合成结束释放模型；到点只播放缓存，无需打开界面。模型资源逐文件 SHA-256 校验。
- 主页的已完成记录自动收起到“任务收纳”，按日期整理并支持搜索；主页和收纳列表按需创建卡片，减少条目过多时的构建开销。
- 左滑任务提供“归档保留／删除任务／取消”。归档保留全部提醒参数，停止后续提醒；在收纳中编辑保存即可再次使用。过期的一次性任务复用时预填未来时间，保存前仍可修改。
- 划掉提醒通知先停止本轮重提醒，再显示静默的归档／删除选项；不选择会保留记录，循环任务继续原循环。归档或删除会停止后续循环。锁屏操作要求解锁，过期按钮不能操作编辑后的新任务。
- 设置中可关闭“划掉通知后询问整理方式”。归档状态随备份导入导出，导入归档记录不会自动恢复排程。
- 延续固定签名，可覆盖更新；保持原生系统闹钟和后台提醒机制。

常规测试不执行手机或模拟器重启。本次未修改开机恢复调度核心。荣耀100的扬声器听感、真实内存峰值和系统后台策略仍需真机验证。
