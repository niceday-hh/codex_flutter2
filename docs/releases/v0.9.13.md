# 超级提醒 v0.9.13（24）

本版只改观感，不改功能：

- 字重从 43/49 处 ≥w600 收敛为三档：正文 400、强调 500、标题 600。首页一屏的粗体层级从五个降到两个。
- 时间降一级：主卡 40/w800 → 34/w600，卡片 26/w800 → 21/w600；正文行高 1.5 → 1.62，长段不再挤。
- 中文一律去掉负字距，只有等宽数字保留 −0.2～−0.6。此前 40px 中文在 −1.2px 下笔画相接，粗体糊成块。
- 分组头重做：由 ink/w700 改为 muted/w500，左侧 14×2 的强调色短横，右侧 1px 细线延展，高度 44 → 40。深色下不再是一条黑底上压着最亮白字的横带。
- 深色表面由两档改三档：#0E0D13 页面 / #191622 卡片 / #221E2D 浮层，浮层用于详情、设置与对话框。正文由 #F3EFFA 降到 #E9E4F4，仍是 14.4:1（AAA），夜间刺眼感减弱。
- 主卡投影跟随强调色，青碧主题下不再出现紫色光晕。

新增四条守卫测试：只允许 400/500/600 三档字重、除等宽时间外禁止负字距、时间字号上限、深色三档表面的亮度关系与正文 AAA。数据结构、备份格式、包名与签名不变，可直接覆盖安装。详见[版本说明](docs/releases/v0.9.13.md)。
