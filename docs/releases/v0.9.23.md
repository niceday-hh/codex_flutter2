# v0.9.23 · 历史任务标记与离线识别模型后台保留

## 历史任务的信息更完整

每条历史任务在正文下方显示两类图标文字：重复方式为「仅一次」「每天」或具体的每周规则；语音配置为「语音开启」「语音关闭」或「语音跟随默认」。图标和文字复用首页的主题色标签，跟随四套强调色及浅深主题，小屏自动换行。

这些标签描述任务保存的配置，不表示已结束的循环仍在运行。历史记录的音频运行状态本来会返回关闭，因此改为读取实际保存的语音开关；跟随默认的任务明确标注继承关系，不用今天的默认值推断过去是否播报。查看标签不加载识别模型、TTS模型或角色图片。

## 后台保留多久，由设置决定

在「设置 → 语音录入 → 模型与性能」新增「离线识别模型后台保留时长」：

| 选项 | 行为 |
| --- | --- |
| 立即释放 | 退后台后请求释放已加载的识别模型 |
| 15秒 | 短暂切换应用时保留模型 |
| 30秒（默认） | 返回应用时尽量复用本次已加载的模型 |
| 60秒 | 延长复用窗口，同时更久占用模型内存 |

后台仍立即请求关闭麦克风，仅保留已经加载的Paraformer识别模型。保留时长不等于持续录音、不主动在后台预热，也不保证系统会维持进程存活。安装包不会因为缓存时长增加而加入新的模型或图片。

计时从真正进入后台开始，重复暂停通知、慢速停止录音或模型准备结束不会延长窗口；返回前台取消计时。若进程被系统暂停，恢复时还会检查保留期限，避免迟到的计时器让已过期缓存继续复用。旧的停止录音回调不会主动释放新一轮前台的模型。

内存压力、应用销毁和VITS播报合成仍允许提前请求释放。正在使用的识别会话按原有引用计数安全结束，TTS继续等待识别模型完全关闭，避免两套大模型同时常驻。应用内部切换Tab继续复用前台模型，不重新触发预听。

## 设置搜索与保存反馈

搜索「后台」「保留」「模型」「预热」「释放」等关键词可找到新参数，并预览当前值。保存后直接在设置分类弹窗内显示反馈；再次打开或重新启动应用时读取保存的选择。旧安装没有该参数时使用30秒默认值。修正部分旧说明中仍写前台闲置20秒回收的过时描述。

## 验证与升级

功能分支通过Flutter静态检查、208项Flutter回归、13项实际界面截图检查、Android APK编译、全部原生单元测试和MNN适配器调试编译。覆盖四档时长、快速返回、慢停录、延期安全释放、内存／TTS提前释放、参数校验与持久化、搜索预览，以及四套强调色×浅深主题下的320dp布局。

正式发布另由现有流水线执行完整模型打包、固定签名校验、Android API 33／35回归及发布资产校验。自动化生命周期测试使用模型／录音替身，未测量真机后台进程存活和内存曲线；实际缓存可用时长仍受手机系统影响。

版本为 **0.9.23+34**，沿用固定包名和发布签名，可覆盖安装现有同签名版本并保留备忘录及设置。原有TTS模型、音色、角色图片和提醒排程规则保持现有实现；本次不作语音质量或持续滚动帧率提升的声明。
