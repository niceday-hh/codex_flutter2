# 超级提醒 v0.9.31

- 详情弹层随内容收高，最高占可用高度的 90%。短提醒的操作区紧接正文，长文、大字号或音频候选展开后可滚动，底部保持编辑入口。
- 历史任务显示原计划时间与历史状态。待提醒任务将下次时间、快捷延后和指定时间放在同一区域。待确认任务保留滑动确认。
- 短提醒用 23sp，长文用 19sp 和 1.55 倍行高。音色放到音频标题旁，试听、换一版和保存音频按可用宽度并排或换行。
- 横幅和竖立绘在页头内取景、渐隐，宽图使用独立图区，无图直接显示正文。页头贴图的尺寸与弹层高度解耦，展开正文时可以复用缓存。

Android arm64，版本 0.9.31（42）。沿用固定签名、包名与离线语音模型，可覆盖安装 v0.9.30。
