# 超级提醒 v0.9.9（20）

本版继续只改观感，不改功能：把"时间"和"文字"在视觉上拉开层级，把卡片上的三个标签收成一个，给首屏补上一层品牌光；并在四处交互点加入一次性动画。数据结构、备份格式、包名与签名均不变。

## 层级：先看见时间，再读文字

- 卡片时间由 23px / w700 改为 26px / w800，字距 −0.8；标题由 15px 提到 16px / w600。此前两者只差 8px，扫视时时间并不比文字更先被读到。
- 主卡时间由 38px / w700 改为 40px / w800，字距 −1.2；正文提到 18px / w600，并新增独立字阶 `heroTime`、`cardTitle`，不再就地写 `TextStyle`。
- 主卡的日期行只在 `repeat != 'none'` 时拼接重复规则，"仅一次 · 仅一次"这类重复信息不再出现。

## 密度：一张卡只说一件事

- 卡片右下由最多 3 个胶囊标签改为「最多 1 个状态标签 + 一行灰字」。状态（未读 2/5、未启用、已结束）留在标签里，日期、重复规则、语音状态合进同一行，超出省略。
- 卡片内边距 16 → 13／14，卡片间距 12 → 10，主卡内边距由 24 → 22/20/21。同样的屏幕高度里，一屏能完整看到多一条提醒。
- 未读色由深棕改回亮琥珀 `#D2761E`（白底 3.4:1），左侧竖条与未读标签同色；标签底改 `#B35F12` 配白字（4.7:1）。非文本图形按 WCAG 1.4.11 的 3:1 即可，此前的棕色在 4px 宽度上读起来像污渍，反而压住了唯一需要跳出来的状态。

## 光感：有光源，而不是一块纯色

- 主卡顶部加一层 15% 白色渐变（到 68% 高度处收束为零），配合品牌色投影由 `22/10` 提到 `26/12` 并染上 `#4A2BC4`，卡片从"贴上去的色块"变成"被打亮的表面"。两层都是静态填充，没有模糊。
- 首屏背景加一层品牌径向光晕（`#7252F6` 11%，从顶部中心向外到 78% 处消失），包在 `RepaintBoundary` 里、`IgnorePointer` 之下，滚动时不重绘，整块代价是一次填充。

## 动画：只在被触碰或首次出现时运行

- 首屏入场：主卡与列表项淡入并上移 10px，520ms 完成，逐项错开 85ms，最多前 6 项参与，之后直接出现。动画结束后 `MemoReveal` 返回裸子树，不留 `Opacity` 与 `Transform`。
- Tab 切换：200ms 淡入（从 74% 透明度起）加 6px 上移。包裹在 `IndexedStack` 外层，四个页面都不卸载，各自的滚动位置、搜索词与草稿保持原样。
- 按压：可点卡片在按下时缩放至 0.978，历时 110ms，同时阴影由 `card` 收紧为 `press`。缩放层放在 `DecoratedBox` 内层——`RenderTransform` 不参与命中测试，置顶会让点击落在空处。
- 全应用只有 2 个 `AnimationController`，静止时 0 个 ticker 在跑，`.repeat(` 在源码中零出现，并由静态测试守住。

## 修复

- 按钮、对话框、芯片的文字在某些环境下回退到引擎默认字体导致中文显示为方块：`textTheme` 改为在平台排版基线（`Typography.material2021`）上 `merge` 令牌，保留 `fontFamily`，不再整体替换。同时去掉 `FilledButton`／`OutlinedButton` 上会覆盖前景色的 `textStyle`。

## 升级与验证范围

不涉及数据迁移：提醒、历史、角色组、设置与备份格式完全兼容，可直接覆盖安装；已排程的系统闹钟不受影响。

Flutter 3.35.7、JDK 17、arm64。新增三条守卫测试：源码出现 `.repeat(` 即失败；动画完成后仍存在 `Opacity`／`Transform` 即失败；未完成状态必须实际产生透明度与位移。全部 Flutter 测试、原生排程检查、发音时长策略与 Android API 33/35 模拟器回归仍由自动发布流程把关。

界面观感以 393×852 尺寸截图核对，测试环境字体与真机存在细微差异；动画手感、触感与滑动阻尼仍需真机确认。
