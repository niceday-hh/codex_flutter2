# v0.9.26 · 明确任务模式与无标点多任务解析

语音新建页新增单任务／多任务分段切换，跟随现有四种配色及浅深主题。录音和识别期间锁定页面切换，防止正在处理的内容被另一套规则接管。单任务保持原有解析、语音确认及保存流程；手动录音沿用页面已选模式。

每次从首页开始新的免手预听，默认单任务，不继承上一次的多任务选择。可连续说“开始录音，多任务模式，明天九点起床十点学习”，也支持明确说“单任务模式”；模式词只在正文开头作为控制指令识别，不会保存进提醒正文。不新增必须回答的模式询问，也不等待用户选择后才允许继续说。单独说完模式词时继续录音收取正文，仍遵守现有45秒录音上限和后台停麦规则。

多任务模式按时间表达生成候选，不再依赖识别模型补出逗号。支持中文／阿拉伯数字、空格、顿号、连接词，省略日期时沿用前一条明确日期。引号和书名号内的时间不作分界；每条参数从独立默认值生成。规则式解析不等于语义理解，正文内未加引号的时间引用仍可能形成额外候选，必须核对后才创建。

多任务模式即使仅识别到1条也进入专门确认页并明确提示，不悄悄退回单任务。超过10条时明确阻止直接提交，返回修改原话；不会截断后自动创建。确认页将原始文字折叠，每条独立编号、时间、正文、状态及铅笔编辑，支持取消勾选。底部固定创建与返回操作，单条编辑不直接保存；批量失败继续沿用已成功条目不重复提交的规则。

场景模板共用改进后的逐条核对布局。既有角色图、TTS参数与缓存、数据结构、备份及排程规则不变。自定义场景模板仍仅保存在本机，暂不包含在JSON备份中。

版本0.9.26+37；新增无标点识别结果、首页连续语句、默认模式重置、录音期间模式锁定、单条识别提示、原话返回保留、逐条修改和排除等回归，包含四种强调色及浅深主题的实际UI预览。测试结果以本次CI记录为准，不宣称已验证所有真机录音行为。
