# v1.0.0-gemini.3 · 语音录入页静态氛围光与通透声波升级（预发布）

本版本延续 `v1.0.0-gemini.2` 的全栈优化与固定签名构建，重点对标深色模式视觉参考图升级了语音录入页（`lib/voice_page.dart`）与实时录音波形（`lib/recording_waveform.dart`），全程严守零循环动画与 `RepaintBoundary` 高性能约束。

## 语音录入页与声波视觉升级
- **通透声波舞台（`RecordingWaveform`）**：为 33 根对称声波新增独立圆角画布（深色模式配 `1px` 微亮边）与静态双点 `RadialGradient` 氛围光晕（青碧到主题紫渐变）；深色模式下激活态柱体采用低开销宽描边外发光叠加细核心光柱，通透感显著增强，且零离屏模糊与零常驻 Ticker 开销。
- **麦克风主按钮静态光环（`VoicePage`）**：中央录音圆盘外围新增静态径向氛围光晕与 `1.2px` 同心细环（录音激活时平滑外扩增亮），按钮表面增加 `1.5px` 内高光边与主题色柔阴影。
- **倒计时胶囊与输入卡片层次**：录音倒计时 `剩余 X 秒` 升级为圆角胶囊徽章，语音草稿输入框在深色模式下采用 `surfaceAlt` 表面与 `1px` 细描边，层次更清晰。

## 继承的 v1.0 全栈优化
- 保留 `v1.0.0-gemini.2` 全部首页 Hero 徽章、列表左侧状态色条、底部导航选中胶囊、中央 `+` 45° 微旋、方向感 Tab 切换及 Flutter/Android 原生层解耦重构。
- 沿用固定正式签名（`versionCode 46`）与全量回归测试校验，支持直接覆盖安装旧版本。
