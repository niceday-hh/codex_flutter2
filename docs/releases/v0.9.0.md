# 超级提醒 v0.9.0（11）

- 应用显示名、通知和前台提示更新为“超级提醒”；保留 com.niceday.memo.stable 与固定发布签名，支持覆盖更新。
- 新增可选的15秒前台预听指令，支持“开始录音”“打开录音”“切换到录音”，也支持与提醒需求连说。首次使用需要系统麦克风授权。就绪后才计算聆听窗口，超时、切后台或锁屏时停止聆听。
- 集成离线 Silero VAD v5，默认正文连续5秒无有效人声后停录，可设3至10秒或关闭自动停录。复用同一录音器，小块PCM送后台线程处理；保留45秒上限。
- 识别完成只弹出需求确认卡片，不使用TTS播报确认摘要。支持语音“确认／重新录音／取消”和按钮；确认阶段20秒未操作则保留草稿、关闭麦克风。严格区分正文“确认订单”和确认指令。
- 录音末尾静音不计入倒计时基准。日期、时间不完整、存在解析歧义或目标已过期时不直接保存，允许重新录音或手动编辑；迟到的识别结果与重复确认不重复创建任务。
- 交互期间复用识别模型，新的VITS生成任务等待交互结束，避免确认聆听被模型装卸打断。实际提醒的语音生成与播放仍沿用原有设置。
- 日历重新显示保留的已完成／已归档任务，按原计划日期归类，与当天待提醒任务分区显示。这里只展示现存任务，不补造循环任务的逐次历史，也不恢复已删除或编辑覆盖的旧版本。
- 新增“我的角色组”，可新建、命名、编辑、删除成员；固定选择和随机选择都可按自定义组筛选，并与配音来源、角色性别取交集。空池明确提示，已创建任务的选定音色不随组修改而变化。
- 角色组随备份导出；导入同编号组时分配新编号，并更新导入任务引用，保留本机组及任务。
- Silero VAD固定模型版本并校验SHA-256，APK完整性检查包含VAD资产；云端增加真实VAD推理、语音流程、日历历史和角色组回归检查。

免手预听默认关闭，可在“设置→免手语音操作”开启或试用。中文／日文仍表示配音来源，当前按中文文本朗读。
本轮不执行手机或模拟器重启测试，未修改开机恢复调度核心。YOYO是否能准确唤起“超级提醒”、荣耀100实际录音体验、耗时和内存仍需真机验证。
