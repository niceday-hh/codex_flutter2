# 超级提醒 v0.9.8（19）

本版不改变任何功能行为，只做界面与渲染成本的重构：统一设计令牌、把散落的手写样式收成组件，并拆掉三处会持续消耗帧预算的实现。数据结构、备份格式、包名与签名均不变。

## 可读性与可达性

- 次要文字颜色由 `#8A859C` 调整为 `#6B6484`，白底对比度从 3.31:1 提升到 5.18:1，正文小字达到 WCAG AA。
- 新增 `brandInk`、`warning`、`danger` 三个语义色，紫色标签底、权限提示条、错误提示的对比度分别为 6.65:1、5.93:1、5.55:1。
- 输入框补 `outline` 边界（白底 3.58:1），此前「画布色填充 + 无描边」在白色卡片里几乎看不出输入区域。
- 全局清除 11px 字号，最小正文为 12px。
- 首页主卡、提醒卡片、权限横幅、日历日期格、语音录音键五处恢复可见按压反馈；此前这些位置可点击但没有任何涟漪。
- 倒计时、时间戳、日历数字启用等宽数字，跳秒时不再左右抖动。

## 设计系统

- 颜色收敛为 10 级品牌阶、7 级中性色、6 个语义色；字号收敛为 8 档正文 + 3 档数字；圆角收敛为 5 档；间距统一到 4pt 阶。
- 令牌以 `ThemeExtension` 注册，组件通过主题取色，后续接入深色模式不需要逐个改组件。
- 抽出 `MemoCard`、`MemoTag`、`MemoEmptyState`、`MemoSectionHeader`、`MemoTextField`、`MemoBanner`、`MemoSheet`、`MemoSlideToConfirm`、`MemoHint`；首页、日历、设置首页、设置面板、语音确认、提醒详情、历史、角色组、语音页均改用组件，旧的 `Surface`、`Tag`、`emptyState()`、磨砂面板实现已删除，不保留并行版本。

## 渲染成本

- 语音流程的 1 秒计时器不再通知整棵树：倒计时改为独立 `ValueNotifier`，三处显示各自订阅，`IndexedStack` 内四个页面不再每秒重建一次（日历一次重建包含 35～42 个日期格）。
- 语音确认面板去掉全屏 `BackdropFilter`（`sigma 16`，覆盖约 92% 屏幕高度）后的遮罩，改为不透明白卡加 20% 遮罩，视觉基本一致但不再需要离屏纹理模糊。全应用实时模糊由 2 处降为 0。
- 日历的圆点判断改为按「提醒列表快照 + 月份」缓存的日期集合，格子查表为 O(1)，不再每格遍历全部提醒；缓存键绑定列表实例，载入新数据自动失效。
- 音色选择列表加 `itemExtent: 76`，滚动偏移计算为 O(1)；搜索加 160ms 防抖，804 条候选不再逐键重算。
- 「滑动确认已读」由 `Slider` 换成整条 56dp 的滑动条，命中区域更大，阈值 88%，未达阈值松手 140ms 回弹，不使用 ticker。

## 升级与验证范围

不涉及数据迁移：提醒、历史、角色组、设置与备份格式完全兼容，固定包名与签名不变，可直接覆盖安装。已排程的系统闹钟不受影响。

Flutter 3.35.7、JDK 17、arm64。本版新增两组静态守卫测试：出现裸色值或小于 12px 字号、重新引入 `BackdropFilter`、倒计时回退为整树通知、滑动条短拖触发确认，都会使测试失败。全部 Flutter 测试、原生排程检查、发音时长策略与 Android API 33/35 模拟器回归仍由自动发布流程把关。

界面观感以 393×852 真机尺寸截图核对，测试环境字体渲染与真机存在细微差异；实机字体、触感反馈与滑动阻尼仍需真机确认。
