# v0.9.22 · 任务详情缓存、首页刷新与滚动绘制

## 打开任务详情

人物图不再随每次关闭弹窗立即从解码缓存移除。保留最近显示的最多 6 张图片，并将这些图片的估算 RGBA 像素总量控制在 6 MiB 内；超出时淘汰最久未使用的条目，收到内存压力通知时清理。此数值不是整个 APP 或 GPU 的内存上限。图片仍按实际使用加载，不预载全部角色，不降低现有清晰度。

构图与配色目录提前随应用初始化加载。详情弹窗显示期间，语音状态和任务数据仍正常更新；背后首页的重建暂时合并，关闭弹窗后统一显示最新数据。详情内的完成、延后和编辑操作继续生效。

## 滚动和操作状态

外层内容按块隔离绘制，保留原有的正文独立滚动区域与底部固定编辑按钮。滚出可视范围的内容继续保留状态，避免试听被中断、候选音频被释放或正文位置丢失。浅深主题、人物焦点、色雾和渐隐保持原样；没有增加图片文件或实时模糊。

## 验证范围

Flutter 分析无问题，184 项 Flutter 回归测试通过，另有 11 项人物弹窗检查通过。验证包括关闭后图片缓存复用、有限缓存和内存压力清理、详情期间首页不重建且关闭后显示新数据、小屏大字号按钮可达，以及滚动不结束试听、关闭详情才停止试听。

Android 15 模拟器使用同一 AOT Profile 测试框架对比 v0.9.21 与优化实现。详情见[测试说明](../detail-sheet-performance.md)。模拟器的原生任务存储、录音和语音生成使用固定数据替代，结果只用于比较实际 Flutter 页面和图片的渲染，不代表真机帧率、真实麦克风争用或实际提醒调度的验证。

版本号为 **0.9.22+33**。正式 APK 的原生测试、Android API 33/35 检查及固定签名校验，仍由现有 Android 发布流水线执行；性能测试包使用独立测试壳，不作为正式安装包分发。
