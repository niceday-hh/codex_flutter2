# v0.9.20 · 角色背景、日夜适配与详情弹窗排版

## 本版变化

点击任务打开的上滑详情弹窗，现在会按该任务实际的语音音色显示角色图。这是编辑提醒前查看、试听和快捷调整时间的面板；点击底部「编辑提醒」仍进入原有表单。

- 横幅图放在顶部右侧；竖图按比例延展到卡片背后，边缘允许随屏幕裁切，人物主体与左侧文字错开。
- 浅色主题使用随强调色变化的浅色遮罩，深色主题使用深色遮罩。文字区域保持高遮盖率，右侧人物保留颜色，底部渐隐。
- 时间、日期、正文、播报音色分层排布；状态、延后、音频分为独立实色卡片，图片不透过正文和按钮。
- 音频面板保留一个实心主按钮「试听提醒」，下方「换一版」「保存音频」作为次操作。
- 底部「编辑提醒」使用主题浅底填充并固定在滚动区之外；长文本和大字号不会把它推到屏幕外。
- 四个快捷延后选项全部保留：+15 分钟、+30 分钟、+1 小时、明天此时。窄屏自动换行。
- 未读提醒仍使用滑动确认；「完成本次」、指定时间、试听、音频版本选择与导出沿用现有逻辑。

## 图片、音色与性能

内置 **189 张 WebP，约 6.55 MB，覆盖 244 个音色 ID**。多语言或同角色的不同音色可以共享图片，不会重复打包。缺少配图的音色、未开启语音的任务自动回退到主题背景。

原生状态通道新增只读的 `resolvedSpeechVoice` / `resolvedSpeechEnabled`，沿用合成模块 `SpeechSettings` 的解析结果，避免「跟随默认」与随机音色的图片选错。图片展示不会再次抽取随机音色。字段不写入备忘录或备份，不改变已有音频缓存键。

图片全部本地读取。目录只加载一次，弹窗不会等待图片解码再打开；仅解码当前角色，单张 RGBA 像素占用小于 1.2 MB，离开或换角色时清理对应图片缓存。没有全量预加载、网络图片、循环动画或运行时高斯模糊。

映射目录见 `assets/character_art/art_catalog.json`；来源清单见 `docs/character-art-sources.json`。图片版权归原权利人，收录不代表获得再分发或商业授权；使用范围仍需遵守各资源方条款。

## 构建与校验

沿用 Flutter 3.35.7、JDK 17、ARM64 构建链和固定发布签名。包名 `com.niceday.memo.stable`，版本号 **0.9.20+31**，可以在同签名版本上覆盖安装。

发布流水线运行 Flutter 分析与全量测试、原生单测、调度与语音节奏检查，以及 Android API 33 / 35 模拟器测试，全部通过后才发布。新增检查覆盖实际音色解析、244 条映射、189 个文件、横竖图与缺图在浅深主题下的操作可达性，以及 320dp / 1.6 倍字号长文本。

Release 中的 `character-ui-previews.zip` 保存六张真实 Flutter 测试渲染（横幅、竖图、无图 × 浅深主题）。截图使用随包的中文字体替代测试字体，正文实际字形以手机系统字体为准；截图不是手机实测或性能基准。

本版不更换 TTS 模型、音频、包名或密钥，不修改任务触发时的通知弹窗。
