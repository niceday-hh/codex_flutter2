# 定时备忘录 v0.3.0

本版让通知展示设置更容易找到，解决提醒自检中多个相同入口难以区分的问题。Android 构建号为 4。

## 主要变化

- 创建／编辑提醒新增“展示方式”：横幅和通知栏、仅通知栏。新增“锁屏显示”：隐藏正文、不在锁屏显示。保持非全屏；锁屏时实际通知正文也做脱敏。
- 设置 → 默认提醒新增默认展示方式与默认锁屏显示；仅用于之后新建的提醒，原提醒仍保留各自选择。初始默认是横幅和通知栏、锁屏隐藏正文。
- 编辑器新增“这条提醒的系统通知设置”，直接打开当前所选样式的系统页面，无须先保存，也不会改变提醒时间或新增任务。默认样式也有对应系统入口。
- 提醒自检保留一个“检查系统通知与锁屏设置”总入口。高级“通知样式”默认折叠，按展示、隐私、振动和有效铃声分组，显示关联备忘数量、当前默认组及系统设置差异；无引用历史通道在应用内隐藏，但保留手机中的原设置。
- 15秒测试使用当前默认的展示、隐私、铃声、振动及亮屏选项，仍只提醒一次。主动选择仅通知栏时，不再错误提示需要开启横幅。
- 相同样式共用系统通道；关闭声音时，不再因为预选铃声不同而生成重复样式。升级复用 v0.2 的兼容通道，保留已有系统手动设置。
- 新展示字段支持备份迁移；旧备份缺失字段时沿用兼容默认值。本机通知通道标识不进入导出文件，也不接受导入文件指定本机通道。合并导入仍不覆盖当前默认设置。
- 修正设备验证报告的延迟字段，避免第二次排程时间覆盖首次送达延迟；验证仍要求首次实际送达延迟小于15秒。

## 安装与系统设置

使用原固定签名和包名 `com.niceday.memo.stable`，可直接覆盖 v0.2.0，不必卸载，保留备忘数据。v0.1.0 的临时签名仍不支持覆盖。

应用展示偏好不能强制覆盖手机中的通知权限、横幅、锁屏显示、勿扰与荣耀后台策略。若界面显示“系统设置与应用偏好不同”，请打开该样式的系统通知设置检查。相同样式的多条提醒共用设置；关联数量统计当前存储的全部记录，包含已完成记录。当前默认样式即使零条记录也保留。
