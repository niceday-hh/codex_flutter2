# 超级提醒 v0.9.29

- 语音页空闲时显示可照读的例句，开始收音后显示真实波形和剩余时间。识别模型加载时仍会提示收音状态。
- 多任务草稿按相邻日期分组，普通行保留勾选、时间、正文与编辑；有歧义的行展开原话和处理选项，底部可定位第一条待核对项。拆分与合并有局部动效，并响应系统的减少动态效果设置。行尾菜单保留合并入口。
- 场景预览底部可直接选择开始时间，选好后同一位置可创建已勾选提醒。单独改时、取消和部分创建后的重试规则沿用现有逻辑。
- 首页合并日期、待办数与场景入口。深色日历的选中日期及日程点依背景选择前景色。
- 角色详情按实际文字宽度与系统字号排版，放不下的正文使用全宽阅读区域。长文支持展开、收起，与整页面共用滚动，底部编辑入口保持可见。

Android arm64，版本 0.9.29（40）。使用原包名、签名与离线模型，可从上一版覆盖安装。
