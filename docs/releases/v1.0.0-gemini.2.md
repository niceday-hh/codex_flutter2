# v1.0.0-gemini.2 · 高感知界面美化、方向动效与原生层重构（预发布）

本版本基于 `v0.9.32` 在 `gemini` 分支进行全栈优化，涵盖高感知界面层次升级、单次物理微交互动效，以及 Flutter 与 Android 原生层架构解耦。

## 界面美化（立即可见）
- **底部悬浮导航栏选中胶囊**：选中标签页新增柔和的圆角胶囊高亮指示器（随 4 套强调色与深浅色自动切换），区分度更清晰。
- **首页 Hero 提醒卡升级**：顶部「下一条提醒 / 待确认提醒」标签升级为半透明玻璃感胶囊徽章，卡片外缘增加 `1px` 细腻内高光描边。
- **提醒列表左侧状态色条**：每条提醒左侧新增 `3.5px` 圆角状态指示条（待确认用琥珀色、待提醒用主题色、历史归档用中性灰），扫视效率更高。
- **日历空态插画与弹窗层次**：日历无提醒页面接入零位图矢量插画（`MemoEmptyKind.history`）；底部弹窗 `MemoSheetShell` 在保持零毛玻璃性能开销下增加 `1px` 深浅色顶缘描边；`memoSnackBar` 接入 `MemoPalette` 语义令牌。

## 动效优化（严守无循环动画预算）
- **方向感 Tab 切换**：底部 4 个页面切换升级为带左右方向感的 `220ms` 轻滑入过渡。
- **新建 `+` 按钮灵动反馈**：中央悬浮 `+` 按钮按下时触发 `45°` 轻旋转与缩放回弹。
- **录音波形与滑动确认**：`RecordingWavePainter` 新增中心余弦包络衰减、振幅色阶渐变与满幅警示色；`MemoSlideToConfirm` 越过 `88%` 阈值触发轻量 `selectionClick` 触觉预反馈，松手采用 `easeOutBack` 弹性回弹；`MemoNumberSwap` 支持双向数字翻滚。

## 工程与 Android 原生层重构
- **Flutter 弹窗协调器**：新增 `lib/sheet_coordinator.dart` 接入 `lib/main.dart`，配套单元测试 `test/sheet_coordinator_test.dart`。
- **Android 原生层解耦**：从 `MainActivity.java` 抽离 `DeviceSettingsNavigator.java`（系统设置跳转 + 定制 ROM 缺页降级兜底，配套 Robolectric 单测 `DeviceSettingsNavigatorTest.java`）与 `ReminderDialogPresenter.java`（修复前台 10 秒自动关闭弹窗的 `Handler` 生命周期隐患）。
- **固定正式签名与回归 CI**：`.github/workflows/gemini-prerelease.yml` 接入 `tool/prepare_signing.py` 与 `tool/verify_apk.py`，支持直接覆盖安装旧版。
