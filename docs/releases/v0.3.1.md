# 定时备忘录 v0.3.1

修复锁屏触发后，解锁仍停留在“有一条待办提醒 · 解锁后查看”的问题；补充振动试振与实际通道诊断。Android 构建号为 5。

## 通知正文修复

旧版在锁屏触发时把真实正文替换为占位文字，之后没有恢复。现在使用 Android 标准私有正文与公开占位双版本，系统随锁屏状态切换，即使 App 进程已结束也能在解锁后显示正文，再次锁屏重新隐藏。

重启后首次解锁前，设备加密排程仍不含正文，通知只使用占位。凭据解锁后通过开机恢复和返回应用补充更新仍在显示的通知；更新保持原时间、次数与未读状态，不主动亮屏，不重新响铃振动，不恢复已划掉的通知。

锁屏隐私由系统设置最终决定。使用“隐藏正文”时，请在系统通知设置中关闭“显示敏感内容”。若系统允许显示全部内容，App 的 PRIVATE 标记不能强行覆盖用户的系统选择；本版界面已明确说明。保持非全屏，不主动解锁。

## 振动说明与诊断

- 一次、两次、三次、长振动支持前台“试振”，预览不改变当前选择、不保存任务。试振请求仍遵循系统静音、勿扰及触感策略，不强制绕过限制。
- 三次是每次提醒内的3段200毫秒振动，段间200毫秒；它与“提醒总次数”是不同参数。“系统默认”由手机决定节奏，不保证次数；从系统选择铃声不导入振动。
- 提醒自检 → 通知样式显示系统通道记录的振动段数或系统默认状态；检测节奏差异，并提供原有系统入口。保持用户已修改的通道，不强制重建或双重振动。
- 系统记录的波形不等于振动马达的实际触感。若试振为三次、通知只有一次，请检查对应系统通道、勿扰、静音及厂商振动策略。

## 安装与验证

沿用固定签名与 `com.niceday.memo.stable`，可覆盖 v0.2.0／v0.3.0，保留数据。发布须通过 Flutter 检查、页面／语音规则、原生状态／备份／通知测试、后台休眠与重启验证，以及 Android 13 安全锁屏的实际 SystemUI 隐私切换测试。

没有进行荣耀100马达与厂商锁屏真机验收，模拟器结果不能替代物理设备实测。
