# v0.9.27 · 应用内截图与先预览场景模板

主界面窗口允许截图，覆盖首页、语音、设置和应用内任务编辑页面。到点提醒的原生弹窗和其他应用上方的悬浮提醒卡片仍使用独立安全窗口，继续禁止截图。锁屏通知正文与锁屏语音播报的隐私规则不变；未新增隐私开关。

点击场景模板的“预览 N 条提醒”直接进入该场景的预览页，先显示开始时／若干分钟后的相对安排，不自动弹出时间调整。顶部“开始时间”初始为未设置；只有点击此行才打开专用“设置场景开始时间”弹窗。取消选择仍留在预览页，选择完成后每条提醒显示实际日期和时刻。未选择开始时间时禁止创建，也不进行通知授权、预占提醒ID或保存任务。

选好开始时间后可逐条编辑、取消勾选并确认创建。再次调整整体开始时间时，普通条目按原有偏移重新安排；已经单独修改过时间的条目保留其时刻，并标注“时间已单独调整”。只修改正文或提醒方式的条目仍会随开始时间移动。部分创建成功后整体起点固定，剩余条目仍可单独修改并重试，沿用稳定ID和不重复创建已成功项的规则。

新预览跟随现有四套配色和浅深主题，正文可滚动，底部操作固定。语音单／多任务确认和已有模板的数据结构不变；自定义场景模板仍仅保存在本机，暂不包含在JSON备份中。

版本0.9.27+38，沿用固定包名、签名和完整离线模型。新增真实模板入口、取消时间选择、时间偏移创建、单独时间保留及320dp大字布局回归。测试结论以对应CI记录为准，不宣称完成真机截图或所有厂商录屏验证。
