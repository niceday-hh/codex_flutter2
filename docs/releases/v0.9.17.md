# v0.9.17 · 悬浮胶囊底栏、冷调纸面与药丸分段

这一版参照「鲸记账」的视觉语言重做应用外壳：底栏从贴边的 Material 条形变成浮起的胶囊，主操作被放进胶囊正中；页面底色从淡紫偏向冷灰蓝，卡片圆角放大到 28，阴影改成双层；历史页补上一个药丸分段。

## 底栏：一条浮起的胶囊，中间是主操作

原来的底栏是 `NavigationBar` 贴底 + 一条 0.6px 顶线，新建按钮是右下角一个独立的圆形 FAB。这两件东西在说两种语言：一个是通栏的分区条，一个是浮在内容上的圆片；列表滚到底时，FAB 还会压住最后一行。

现在底栏是一个 64dp 高、28dp 圆角、左右各留 16dp 的胶囊，浮在页面之上 10dp。四个目的地分成 2 + 2，中间 76dp 的缺口里坐着一个 56dp 的渐变圆盘 —— 导航的中线就是应用的主操作。

- 选中项：图标换成实心、放大 6%、颜色 `brand600`；文字 w600、同色。两项都是 `Animated*`，140–200ms 收敛后不再 tick。
- 圆盘：`brand400 → brand600` 对角渐变，外面一圈 3dp 的胶囊色描边。这圈描边替代投影——圆盘有一半沉在胶囊里，任何长到能被看见的投影都会在它下面淤成一块紫色月牙，描边则是把圆盘从胶囊上「切」出来。
- 按压：圆盘缩到 0.94 并给一次 `mediumImpact`；tab 只给 `selectionClick`。
- 批量选择时整条底栏不建：此时每一次点击都是勾选，底下一个「新建」圆盘是个陷阱。切换只有一次布局变化。

tab 切换仍然是 `IndexedStack`，没有交叉淡入。取而代之的是一次约 14dp 的上移（屏高的 1.6%，`SlideTransition`，200ms）：四个页面本来就各自包在 `RepaintBoundary` 里，移动图层只需要重新合成，不重绘里面的列表——这和「包整页 `Opacity`」是两件事。测试里那条「tab body 从不经过淡入层」的守卫仍然通过。

## 色调：冷一点的纸

页面底色 `#F8F6FC → #F4F5FA`。旧值带一点品红，白卡放上去偏暖；新值只往蓝灰走了一步，卡片才开始像「浮在纸上」而不是「比纸浅一点」。

深色三档同步偏冷：`#0E0D13 / #191622 / #221E2D → #0B0C14 / #181A28 / #23263A`，发丝线 `#2E3146`。正文 `#ECEEF7` 对卡片 15.0:1，muted 7.4:1，outline 6.4:1，仍然全部过 AAA/AA。

背景光斑从「顶部一团紫」改成两团：右上 10%、左下 6%，颜色取自当前强调色。之前 `MemoGlow` 用的是写死的紫，切到青碧之后页面还顶着一片紫云；现在光斑跟着 ramp 走，和 v0.9.15 做的「表面随强调色」终于一致。两团都画在同一个 `RepaintBoundary` 里，滚动时零成本。

## 主卡与卡片

- 圆角 `26 → 28`。26 在 393dp 宽的屏幕上仍然读作「圆角矩形」，28 才进入「曲线」。
- 卡片阴影从单层 14/5 改成双层：24/10 的接触影 + 6/2 的贴地影。单层深阴影像描边糊了，双层才是高度。
- 主卡投影 15%/22 → 26%/30，在新底色上才看得出「发光」。
- 主卡右上角加了一层径向柔光（中心在卡片外的右上方）。第一版用两个实心白圆，边缘清晰得像水印；径向渐变没有边可循，才是光。
- 日间渐变从 `c600 → c800` 提到 `c500 → c700`（`#5B3FD9/#3E2699 → #7252F6/#5334CC`）：深的那一档在新底色上读起来像一块板，而 500 对白字仍有 4.5:1，卡片可以整幅用强调色。
- 夜间渐变提亮并偏紫：`#332F7A/#1A1F52 → #4A3AA8/#241A63`。白天档从 17:00 延到 19:00——18:00 打开应用不该是午夜色。

## 页眉与历史页

页眉右上角从两个裸图标改成 42dp 的圆形按钮：白底、0.6dp 发丝边、一层短接触影。裸 `IconButton` 没有表面，在 34px 宋体标题旁边像两个飘在页边距里的字形。

历史任务页：

- AppBar 背景改成 canvas，标题用 21px 衬线，与首页的标题语言接上。
- 搜索框下面加药丸分段：全部 / 已完成 / 已保留。轨道是 `surfaceAlt`，滑块是真表面（白 + 短影），选中项读起来像一个实体开关而不是一块淡色矩形。切换会清空选择集，避免「筛选后还勾着看不见的行」。
- 计数改成「共 N 条」/「M / N 条」，不再出现「1 条 · 共 1 条」这种重复。

日历的选中日从 44dp 的圆角方块改成圆盘。14dp 圆角在 44dp 上还是「方块」，而一张 28dp 圆角的卡片里再放一个方块，等于同屏两套圆角语言。

## 校验

新增一组截图场景（底栏、日历、设置、历史筛选），只在 `MEMO_UI_PREVIEWS=1` 时运行，CI 不依赖系统字体。

全量 **136 通过 / 9 跳过 / 1 失败**，失败项仍是 `vad_model_test` 缺 `.so` 的沙箱基线问题。测试里的 `NavigationBar` 引用改为 `MemoTabBar`，`selectedIndex` 改为 `index`；页眉的历史入口从 `IconButton` 换成 `MemoIconButton`，对应断言同步。

`every raw colour lives in design_tokens.dart` 与「字号不低于 12px」两条守卫都仍然通过：新组件没有写死颜色，底栏标签是 12px（参考稿的 9.5px 在这个字号下限之上会被拒）。

数据结构、备份格式、包名与签名不变，可直接覆盖安装。
